# 月&季 RSI6「★5 分批卖出」实施方案（待确认）

> 本文档仅为方案，**确认后再改代码**。第 9 节列出需要你拍板的 4 个问题及我的建议默认值。

## 1. 背景与目标

当前「月&季 RSI6 百分位策略」在满足卖出条件（月/季 RSI6 双超买 + **持有满最低天数（默认 365 天，可配置）** + 收益率门槛）时**一次性清仓**，`sellDate` / `sellPrice` / `returnRate` 均为单笔卖出。

本次改为**分批卖出**：

- 卖出信号成立后，按固定批次（默认 **4 次**，常量可配置）分次卖出，每批间隔默认 **7 天**（常量可配置）。
- 每批按「本批卖出价 vs 同一买入价」分别计算收益率，再取**算术平均**作为该笔交易的收益率。
- 「买入&卖出报告」Excel 的「收益率」列改名「**平均收益率**」，并按批次数量**动态新增 N 列**各批收益率。
- 详情页 `RsiFilterMark` 内「月&季 RSI6 百分位策略」表格复用同一套分批逻辑与列。

单周期策略（周/月 RSI6 百分位）**不在本次范围**，保持一次性卖出。

## 2. 可配置常量（`stockUtils.ts`）

```ts
/** 月&季 RSI6 ★5 卖出的分批次数（可配置，默认 4；配为 1 则退化为一次性清仓） */
export const MQ_SELL_TRANCHE_COUNT = 4;

/** 分批卖出相邻两批的间隔（自然日，可配置，默认 7）
 *  仅当 MQ_SELL_TRANCHE_COUNT > 1 时生效，且强制要求 > 1 天（否则自动兜底为 2 天） */
export const MQ_SELL_TRANCHE_INTERVAL_DAYS = 7;

/** 月&季 RSI6 ★5 配对卖出的最低持有天数（自然日，可配置，默认 365 ≈ 满 1 年）
 *  - 未满该天数时，即使月/季 RSI6 双超买、收益率也达门槛，也不卖出，继续持有等待后续信号；
 *  - 该常量同时作为本策略年化收益率的计算门槛（未满则展示 --）；
 *  - 仅作用于「月&季 RSI6 百分位策略」的 ★5 配对，周/月单周期策略不受影响。 */
export const MQ_SELL_MIN_HOLDING_DAYS = 365;
```

生效值统一由内部辅助函数归一化，所有消费方只读归一化结果，避免多处 `Math.max` 口径漂移：

- `getSellTrancheCount()` = `Math.max(1, Math.floor(MQ_SELL_TRANCHE_COUNT))`
- `getSellTrancheIntervalDays()` = 批次 > 1 时 `Math.max(2, Math.floor(MQ_SELL_TRANCHE_INTERVAL_DAYS))`；批次 = 1 时不使用
- `getMinSellHoldingDays()` = `Math.max(1, Math.floor(MQ_SELL_MIN_HOLDING_DAYS))`

> 「当配置大于 1 次，天数得大于 1 天」：配置为 0/负数/1 时自动兜底为 2，并在常量注释中写明。

## 3. 口径定义

设买入日 `B`、卖出信号日 `S`（即当前代码中触发卖出的那个月末交易日）、批次序号 `i = 1..N`。

### 3.1 各批卖出日与价格

| 批次 | 目标日 | 实际卖出日 | 卖出价 |
|------|--------|------------|--------|
| 第 1 批 | `S`（T+0） | `S` 本身（信号当日） | 信号当日的 `收盘`（与现有 `sellPrice` 相同） |
| 第 i 批（i≥2） | `S + (i-1) × 间隔天数` | 价格序列中**第一个 ≥ 目标日、且严格晚于上一批实际卖出日**的数据点（目标日非交易日时自动顺延到下一个交易日的收盘价） | 该数据点收盘值 |

- 价格序列：个股/指数/大宗商品/外盘期货用**日 K**；基金用接口原始序列（稀疏月度，累计收益率口径）。
- 「严格晚于上一批」用于避免数据稀疏时（如基金月度数据）后几批反复取到同一个交易日。
- 若找不到满足条件的数据点（信号太新、后续还没数据）：该批标记 `executed = false`，后续批次同样不执行。

### 3.2 收益率与平均值

- 每批收益率：`calculateHoldingReturnRate(买入收盘, 本批卖出收盘, closeValueType)`（基金仍走 `cumulativeReturn`）。
- **平均收益率** = 所有 `executed = true` 批次的收益率算术平均（保留 2 位小数）。
- **卖出条件判定**（在信号日一次性判定，四个条件取「与」）：
  1. 月 RSI6 ≥ `MONTHLY_RSI_SELL_PERCENTILE`(85)；
  2. 季 RSI6 ≥ `QUARTERLY_RSI_SELL_PERCENTILE`(85)；
  3. **持有天数 ≥ `MQ_SELL_MIN_HOLDING_DAYS`(365 自然日，可配置，见 `getMinSellHoldingDays()`)**；
  4. 收益率达门槛 `MQ_SELL_MIN_RETURN_PCT`(15)。

  任一条不满足（尤其第 3 条未满 1 年）→ **不卖出、继续持有**，等待下一个同时满足四条条件的信号。达标后第 2~N 批按计划执行，不再重复校验卖出条件（与你上次确认的口径一致）。

### 3.3 持有天数 / 年化 / 回撤（已确认）

- `sellDate` 语义不变 = **首笔卖出信号日**（图上卖点、配对状态机、RSI 卖出值都用它）。
- `holdingDays` **保持不变** = `B → S` 的日历天（不延到后续批次）；因卖出需满 `MQ_SELL_MIN_HOLDING_DAYS`(365)，该值恒 ≥ 365。
- `annualizedReturn` = `calculateAnnualizedReturn(平均收益率, holdingDays)`，仅 `holdingDays ≥ getMinSellHoldingDays()`（默认 365）才计算。
- 「最大回撤率」观察区间**保持不变** = `B → sellDate`，`computeHoldingDrawdown` 无需改动。
- Calmar = 年化收益率 / 最大回撤率，口径不变。

### 3.4 配对状态机

与现状一致：卖出信号成立（四条条件全部满足）即把该 ★5 买点标记为已配对并释放持仓，允许下一笔 ★5 买点建仓（分批窗口内出现的新 ★5 买点不重复建仓）。**未满 365 天或收益率不达标的卖出信号直接跳过、不写任何卖出字段**，持仓保持到下一个满足条件的信号。

## 4. 数据结构

`MonthlyQuarterlyPercentileBuyPoint`（`stockUtils.ts`）新增：

```ts
/** 单批卖出明细 */
export interface SellTrancheDetail {
  /** 批次序号，从 1 开始 */
  index: number;
  /** 目标卖出日（信号日 + (index-1) × 间隔天数，YYYY-MM-DD） */
  targetDate: string;
  /** 实际卖出日（>= 目标日且晚于上一批的首个数据点；无数据时不填） */
  sellDate?: string;
  /** 本批卖出价（与买入价同口径） */
  sellPrice?: number;
  /** 本批持有天数（买入日 → 实际卖出日） */
  holdingDays?: number;
  /** 本批收益率（%） */
  returnRate?: number;
  /** 是否已执行（数据不足时 false） */
  executed: boolean;
}
```

买点新增字段：

```ts
/** 分批卖出明细（批次 = 1 时为单条，等同一次性卖出） */
sellTranches?: SellTrancheDetail[];
```

`returnRate` 字段**语义改为平均收益率**（字段名不变，避免大面积改名）；`holdingDays` 仍为 `B → 首笔卖出信号日`。

`MonthlyQuarterlyPercentileParams` 新增可选参数：

```ts
/** 卖出取价序列（日频或接口原始频率，需含 日期/收盘）；缺省时退化为用月线取价 */

```

调用方传入：
- `buyPointCompute.ts` 个股/指数/大宗商品：`rawData`（日 K）

## 5. 核心算法（`analyzeMonthlyQuarterlyPercentile`）

在现有「卖出条件成立」分支内替换单笔卖出赋值：

0. **前置门槛**：先算 `holdingDays = round((m.日期 - 买入日) / 1天)`，`holdingDaysMet = holdingDays >= getMinSellHoldingDays()`；未满则不进入卖出分支（`holdingFiveStarBuy` 保持，继续循环）。
1. 归一化批次/间隔；把 `priceSeries` 按日期升序排好（一次 O(n log n)，无序列时用 `monthlyArr`）。
2. 第 1 批：`sellDate = m.日期`、`sellPrice = m.收盘`、`returnRate = 门槛判定用的收益率`。
3. 第 `i` 批（i≥2）：目标日 = 信号日 + (i-1)×间隔；用二分查找找第一个 `date >= 目标日 && date > 上一批实际卖出日` 的点。
4. 汇总：`sellTranches`、`returnRate`（已执行批次的平均）、`annualizedReturn`（按 `B → 信号日` 的 `holdingDays`）。
5. 其余字段（`sellMonthlyRsi` / `sellQuarterlyRsi` / `sellPrice` / `holdingDays`）保持 = **信号日**的值。

抽取公共函数（避免导出与页面各写一套）：

- `buildSellTranches({ buyDate, buyClose, signalDate, signalClose, priceSeries, closeValueType })`
- `summarizeSellTranches(tranches)` → `{ averageReturnRate }`（只统计 `executed = true` 的批次）

## 6. 导出改动（`buySellReportExport.ts`）

### 6.1 列

- 「收益率」→「**平均收益率**」（值取 `point.returnRate`）。
- 当 `MQ_SELL_TRANCHE_COUNT > 1`：在「平均收益率」之后**动态插入 N 列**：

| 位置 | 列名（已确认） | 值 |
|------|---------------|----|
| 平均收益率 后 | 第1批卖出收益率（T+0天） | `sellTranches[0].returnRate`，未执行为 `-` |
|  | 第2批卖出收益率（T+7天） | `sellTranches[1].returnRate`，未执行为 `-` |
|  | 第3批卖出收益率（T+14天） | `sellTranches[2].returnRate`，未执行为 `-` |
|  | 第4批卖出收益率（T+21天） | `sellTranches[3].returnRate`，未执行为 `-` |

- 列名中的天数由常量计算（`(index-1) × 间隔天数`），改间隔后自动同步。
- 批次 = 1 时不插入批次列，仅保留「平均收益率」。
- **本次不新增**每批卖出日期/价格列（需求只要求收益率列；如需要可再加）。

### 6.2 单元格与汇总

- `toReportCells` 改为按动态列下标生成，保持与表头严格一一对应（现有约定）。
- 汇总行（平均值/中位数）：新增的批次收益率为数值列，**参与**汇总；`平均收益率` 也参与。
- 「买入计划」导出：**不**新增批次列（无卖出），仍为「持有至今收益率 / 持有至今年化收益率」。
- 两个导出的底部汇总行统一扩为 **6 行**（固定顺序）：`平均值` → `中位数` → `样本方差` → `样本标准差` → `总体方差` → `总体标准差`。
  - 统计只基于**明细行**：`runReportExport` 先保存 `detailRows`，再逐个 push 汇总行，避免「平均值」行被纳入「中位数」等后续统计（修复原有的污染问题）。
  - 样本方差 = `Σ(x-mean)² / (n-1)`；总体方差 = `Σ(x-mean)² / n`；标准差为对应方差的算术平方根，与收益率同量纲（%）。
  - 保留 2 位小数；文本/日期/价格类列留空；`'-'` 与空串不参与统计；样本量 < 2 时样本口径留空（总体口径仍可计算）。
  - 含义：方差/标准差衡量各笔收益率的离散程度，越大代表波动越大、结果越不稳定。

## 8. 边界与异常

- 批次 = 1：完全退化为现状（单笔卖出、单一收益率列）。
- 间隔配置 ≤ 1 且批次 > 1：自动按 2 天执行。
- 信号发生在最近，后续批次无数据：未执行批次收益率列导出 `-`，平均只统计已执行批次，不因此丢弃整笔交易。
- 分红/拆股不在处理范围（沿用现有未复权/复权口径，与当前一致）。
- 基金为稀疏月度序列：可能出现多批落在同一个月末，已用「严格晚于上一批」规避重复取价；导入/显示口径仍为累计收益率。
- Worker 结构化克隆：新增 `sellTranches` 为纯数据，无函数，可正常跨线程传递。

## 9. 已确认的决定

| # | 问题 | 确认结果 |
|---|------|---------|
| 1 | 批次收益率列命名 | 「第1批卖出收益率（T+0天）」「第2批卖出收益率（T+7天）」…（按常量动态生成天数） |
| 2 | 信号太新、后续批次未到期 | 只对已执行批次取平均，未执行列显示 `-`；不丢弃整笔 |
| 3 | 年化收益率 / 持有天数 / 回撤基准 | 均以**首笔卖出信号日**为基准（保持现状），最大回撤区间不延长 |
| 4 | 「买入计划」是否加批次列 | 不加（无卖出，保持「持有至今收益率」单列） |
| 5 | 汇总行新增统计指标 | 中位数之后新增「样本方差 / 样本标准差 / 总体方差 / 总体标准差」四行（两种口径都出），并在文案与文档中说明方差/标准差含义 |
| 6 | ★5 配对卖出的持有时间门槛 | **必须在原有卖出条件上增加「持有满 1 年」**，且为 `≥ 365 天`；365 抽成可配置常量 `MQ_SELL_MIN_HOLDING_DAYS` 并加注释说明；原收益率门槛**保留**且不再卖出不足 1 年的持仓；未满足则跳过该信号、等待下一个满足条件的信号 |

另确认：

- 第 1 批为**卖出信号当日（T+0）**，之后 T+7 / T+14 / T+21 共 4 批；
- 卖出门槛只在信号日（T+0）校验一次，后续批次按计划执行、不再校验卖出条件；
- ★5 卖出需**同时**满足「月/季 RSI6 双超买 + 持有 ≥ 365 天 + 收益率门槛」，任一不满足即继续持有。
