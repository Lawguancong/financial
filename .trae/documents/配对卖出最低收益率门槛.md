# 配对卖出「最低收益率门槛」实施计划

## Context

两类「买入&卖出一一配对」目前的卖出条件是「RSI 超买卖出分位成立 **且 区间收益率 > 0**」，导致只要微利（甚至 1~2%）就在下一个超买信号处平仓，卖出质量偏低。

本次提升卖出门槛：卖出必须同时满足 **RSI 超买条件** 与 **收益率门槛**；门槛默认 15%、可配置，且按持有期分两段口径：

- 持有 **不足 1 年**（`holdingDays < 365`）：**区间收益率 ≥ 15%**；
- 持有 **满 1 年及以上**（`holdingDays >= 365`）：**年化收益率 ≥ 15%**。

不满足则继续持有，等待下一个同时满足「RSI 超买 + 收益门槛」的信号。改动要覆盖页面展示、规则文案与导出，并同步 skill。

> **后续变更（★5 配对叠加持有期门槛）**：月&季 RSI6 ★5 配对的卖出在上述收益率门槛之外，**再叠加「持有满 `MQ_SELL_MIN_HOLDING_DAYS`（默认 365 天，可配置）才可卖出」**；未满该天数时即使 RSI 双超买、收益率达标也不卖出，继续持有等待后续信号。因默认 365 天与下文的「满 1 年」边界一致，本策略卖出时实际恒按年化收益率判定。周/月单周期策略不叠加该门槛。详见 `月季RSI6分批卖出方案.md`。

## 口径定义（最终）

- `returnRate` = `calculateHoldingReturnRate(买入价, 卖出价, closeValueType)`（沿用现有，卖出价 vs **第一次**买入价）。
- `holdingDays` = 买入日 → 候选卖出日的日历天（沿用现有 `Math.max(1, Math.round(ms/86400000))`）。
- `annualizedReturn` = `calculateAnnualizedReturn(returnRate, holdingDays)`；持有不足 365 天时为 `null`。
- 判定：
  - `holdingDays < 365` → `returnRate >= 门槛PCT`
  - `holdingDays >= 365` → `annualizedReturn != null && annualizedReturn >= 门槛PCT`
- 卖出的 RSI 超买条件保持不变（月&季：月≥85% 且 季≥85% 分位；周/月单周期：各自 ≥90% 分位）。

- **新增两个可配置常量**（各自贴近对应 RSI 卖出分位常量）：

  ```ts
  /** 周/月单周期百分位配对卖出所需最低收益率（%）：不足1年按区间收益率、满1年按年化收益率 */

  ```
- **新增内部辅助函数**（`calculateAnnualizedReturn` 旁）：
  ```ts
  const isPairSellReturnSatisfied = (
    returnRate: number, holdingDays: number, minReturnPct: number,
  ): boolean => {
    if (holdingDays >= 365) {
      const annualized = calculateAnnualizedReturn(returnRate, holdingDays);
      return annualized != null && annualized >= minReturnPct;
    }
    return returnRate >= minReturnPct;
  };
  ```
- **`analyzeSinglePeriodPercentile`（约 L1458-L1481）**：把 `holdingDays` 计算提到判定前；`if (rsi >= sellThreshold && returnRate > 0)` → `if (rsi >= sellThreshold && isPairSellReturnSatisfied(returnRate, holdingDays, SINGLE_PERIOD_SELL_MIN_RETURN_PCT))`。
- **`analyzeMonthlyQuarterlyPercentile`（约 L1685-L1716）**：同样把 `holdingDays` 提到判定前；`if (returnRate > 0)` → `if (isPairSellReturnSatisfied(returnRate, holdingDays, MQ_SELL_MIN_RETURN_PCT))`；满足时才写入 `sell*` 字段并清空 `holdingFiveStarBuy`。
